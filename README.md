# VR Симулятор Садовода

> **Командный учебный проект (Курсовая работа, 1 курс)**

Проект представляет собой иммерсивный симулятор садовода, разработанный специально для очков виртуальной реальности **Oculus** с использованием плагина **OpenXR**.

---

### 🎮 Игровой процесс
 В процессе игры пользователь может:
* **Выращивать растения:** Сажайте семена и ухаживайте за различными культурами.
* **Торговать:** Собирайте урожай и обменивайте его на внутриигровую валюту.
* **Покупать улучшения:** Покупайте новые, более эффективные инструменты и редкие семена в магазине.
